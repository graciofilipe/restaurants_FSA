# Specification: Display Agent Insights on UI

## Overview
This feature enhances the Streamlit application to automatically display food hygiene and Google Maps research results immediately after they are generated by the AI Agent. The goal is to provide immediate feedback and visualization of the newly gathered insights without requiring the user to manually refresh or query the BigQuery table.

## Functional Requirements
1. **Post-Generation Data Retrieval:** Immediately after the "Generate Agent Insights" process completes, the application must query the `restaurant_agent_insights` BigQuery table for the specific `fhrsid`s that were just processed.
2. **Batch Filtered Results View:** A new UI section (using an expander or a dedicated results area) must appear automatically below the "Generate" button.
3. **Comprehensive Column Display:** This view must display all columns stored in the `restaurant_agent_insights` table, including `cuisine_type`, `review_count`, `average_rating`, `raw_insight`, and `updated_at`.
4. **Contextual Visibility:** Insights should only be displayed for restaurants that have successful records in the BigQuery table. Establishments without insights should not have an entry in this results view.
5. **Session-Scoped Display:** The results view should persist in the current Streamlit session as long as the user stays on the current view or until a new generation action is triggered.

## Non-Functional Requirements
- **Performance:** Data retrieval from BigQuery should be optimized using a `WHERE IN (...)` clause for the processed IDs to minimize latency.
- **UI Responsiveness:** The UI should update smoothly once the background generation tasks are complete.

## Acceptance Criteria
- [ ] After the generation progress bar reaches 100%, a "New Agent Insights" expander appears.
- [ ] The expander contains a table or list showing the specific data retrieved from BigQuery for the batch just processed.
- [ ] All BigQuery columns from the insights table are visible.
- [ ] Restaurants that were not part of the "just now" generation are not included in this specific results section.
- [ ] If an agent call failed for a restaurant, it is gracefully excluded from the summary view.
- [ ] **Deployment Verification:** The feature is verified to work correctly in the production environment hosted on Cloud Run (https://restaurants-fsa-tqzsejpoja-nw.a.run.app).

## Out of Scope
- Historical browsing of all past insights (this track focuses on the "just now" generated batch).
- Editing the insights directly in the UI.
